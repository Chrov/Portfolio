## Reproduce

The source snapshots are included. No paid account or API key is required for the Python analyses.

```sh
python -m pip install -r tools/requirements-analysis.txt
python tools/build_analysis.py
python tools/build_powerbi.py
python tools/build_tableau.py
python tools/publish_cases.py
python -m http.server 4173
```

Open `http://localhost:4173`. The website has no build dependency. Analysis outputs are deterministic for the pinned packages; provenance timestamps and document archive metadata can change.

The distributed Excel workbooks are ready to edit. Rebuilding their formatting uses the Codex-provided `@oai/artifact-tool` Node package (not a public dependency installed by the commands above). With that package available, run `node tools/build_workbooks.mjs`, then `powershell -File tools/finalize_excel.ps1` on Windows with Microsoft Excel installed, and finally `python tools/publish_cases.py`. The finalizer creates native pivot tables, calculates the workbooks and verifies a source-data edit propagates to the demand dashboard. Raw intermediate JSON is generated by the analysis script.
