## Interactive Cases / Casos Interactivos

Eight case studies, each published as an interactive application with a filterable dashboard, "¿Qué nos muestra este gráfico?" under every chart, findings, measured / simulated / expected impact, the 01–07 process, presentation mode and a USD/CLP currency selector wherever amounts appear. Synthetic and fictional data are labelled as such. Hub: <https://chrov.github.io/Portfolio/apps/>

| # | App | Question / Pregunta | Data / Datos |
|---|---|---|---|
| 01 | **[Revenue Intelligence](https://chrov.github.io/Portfolio/apps/revenue-intelligence/)** | Revenue, customers (RFM) and an 8-week forecast vs baselines; BRL/USD/CLP | Olist (Kaggle, real) |
| 02 | **[TalentRisk AI](https://chrov.github.io/Portfolio/apps/talentrisk/)** | Attrition associations, calibrated models, SHAP, fairness audit | IBM HR (Kaggle, **fictional**) |
| 03 | **[Replenishment Forecast Lab](https://chrov.github.io/Portfolio/apps/replenishment-forecast/)** | dbt star schema + walk-forward LightGBM vs baselines for a shadow pilot | Favorita-style (**synthetic**) |
| 04 | **[Campaign Drift Audit](https://chrov.github.io/Portfolio/apps/campaign-drift/)** | Chronological audit of a bank propensity model: drift, deciles, calibration | UCI Bank Marketing (real) |
| 05 | **[Waste & Margin Control](https://chrov.github.io/Portfolio/apps/waste-control/)** | Batch waste at cost by category, season and supplier; CLP/USD | Market stall (**synthetic**) |
| 06 | **[Route Reliability Monitor](https://chrov.github.io/Portfolio/apps/route-reliability/)** | Disruption by day, carrier, route and airport with Wilson intervals | US BTS, June 2023 (real) |
| 07 | **[Demand Baseline Planner](https://chrov.github.io/Portfolio/apps/demand-baseline/)** | ABC classes, rolling-origin backtest and a stock-buffer simulator | Daily demand (**synthetic**) |
| 08 | **[Copper Value Observatory](https://chrov.github.io/Portfolio/apps/copper-observatory/)** | Volume vs price in Chilean copper exports, 1976–2024; USD/CLP | COCHILCO (real) |

Currency conversion uses the average official rate of each dataset's period (Central Bank of Chile observed dollar; ECB for BRL), generated by `analytics/common/fx.py`; percentages never change with the currency.
